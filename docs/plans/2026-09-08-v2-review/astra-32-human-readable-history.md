## Причина и наблюдаемое поведение

История показывает agency/todo/done, технические order keys a0/a1 и JSON checklist. Сохранённые события верны, но пользователю сложно понять, что именно изменилось.

## Что изменится и зачем

Основная история описывает предметные изменения русскими словами; raw details доступны при необходимости и не заменяют понятный рассказ.

## Шаги реализации

1. Выделить formatter event/field-diff в web presentation layer. Использовать общие справочники названий областей и статусов, не менять persisted event payload.
2. Для порядка показывать перенос в колонку/относительно задачи, если контекст есть; при недостатке данных — честное «Изменён порядок», а не выдуманный сосед.
3. Для checklist описывать добавление, удаление, изменение текста, отметку выполнения и перестановку по item ID. Не считать изменения только по текущему порядку массива.
4. Сохранить actor label, время, связь operation/batch, комментарии и outcome. Noop и rejection не изображать как успешное изменение задачи.
5. Добавить безопасный fallback неизвестного поля/старого event version и сворачиваемые технические детали. Исторический title, если он записан, не подменять текущим без обозначения.
6. Согласовать будущие appearance events с отдельной понятной категорией, не смешивая их с количеством изменённых задач.

## Проверки

- [ ] Статус/область/позиция/checklist add-edit-check-remove-reorder, проект удалён/переименован после события, неизвестное поле.
- [ ] Пакет отображается одной операцией с правильными деталями, Undo и rejection описаны без ложного успеха.
- [ ] Читаемость на реальных коротких русских примерах и узком экране; raw export остаётся побайтово прежним.

## Критерий готовности

История отвечает «кто и что поменял» без чтения внутренних enum/JSON; нет выдуманных значений при недостатке исторического контекста.

## Зависимости и границы

Жёстких зависимостей от других планов нет; работать от актуального snapshot исходников.

Текущая запись может отличаться от состояния на момент события. Использовать event evidence, а не реконструировать историю из сегодняшней задачи без оговорки.

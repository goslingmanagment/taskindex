## Причина и наблюдаемое поведение

Неверный пароль показывает Invalid email or password, а мобильная навигация, закрытие диалогов и уведомления имеют английские доступные имена. Видимый русский интерфейс не совпадает с тем, что сообщает screen reader.

## Что изменится и зачем

Пользовательские сообщения и доступные имена текущих сценариев последовательно русские и понятные, технические machine codes остаются стабильными.

## Шаги реализации

1. Составить инвентарь visible strings, aria-label/title, dialog headings/descriptions, toast announcements и auth errors по реальным UI-путям.
2. Переводить auth errors по стабильному code с русским fallback. Не заменять слова в произвольной строке сервера регулярным выражением и не показывать внутренний stack.
3. Добавить русские labels для mobile menu, close, calendar/navigation и действий с иконками. Проверить, что имя описывает действие, а не техническое имя иконки.
4. Вынести небольшой общий словарь повторяющихся фраз. Не подключать крупную i18n-систему только ради одного языка без потребности в переключении локали.
5. Проверить новые планы оформления: «Как в системе», «Светлая», «Тёмная», «Оформление», «Применить», «Отмена» и состояние несохранённого preview должны следовать тем же правилам.

## Проверки

- [ ] Неверный пароль, истёкшая сессия, passkey failure и неизвестная auth error показывают корректный русский текст.
- [ ] Accessibility tree мобильного меню/диалогов/toasts содержит русские имена без пустых/дублирующихся подписей.
- [ ] Длинные переводы не обрезают действия на узком экране; технические API error codes не изменены.

## Критерий готовности

По инвентарю нет необъяснённых английских пользовательских строк; основные сценарии подтверждены browser/a11y inspection.

## Зависимости и границы

Жёстких зависимостей от других планов нет; работать от актуального snapshot исходников.

Не переводить пользовательские названия задач, имена источников и machine-readable поля. Локализация не должна ухудшать диагностику: requestId/code можно сохранить в технических деталях.

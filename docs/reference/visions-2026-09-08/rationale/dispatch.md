# Диспетчерская

Главная — очередь вопросов, которые требуют моего решения, рядом с ожиданиями от команды. Задачи сгруппированы по типу участия владельца. Контекст выбранной строки постоянно открыт справа: следующий шаг, чек-лист, ответственный и дата возврата.

Тёмная спокойная навигация отделяет рабочие состояния. Компактные белые строки позволяют просмотреть несколько обязательств без сканирования большой доски; зелёное выделение связывает выбранный вопрос с его контекстом. Ожидания идут по дате возврата. Небольшая строка ContentOps сохраняет точку возвращения к собственной работе.

Компромисс: диспетчерская лучше подходит для решений, делегирования и ожиданий, чем для обзора стадий большого проекта. Самостоятельная работа находится в соседнем разделе «Мои задачи».

Четыре демонстрационных взаимодействия:
1. Выбор задачи открывает её контекст; на телефоне панель закрывается кнопкой назад или Escape.
2. Разделы навигации и фильтры направлений меняют список.
3. Локальный чек-лист хранит отметки в памяти страницы.
4. Решённый вопрос переносится в «Завершённые» с явным уведомлением о демонстрационном изменении.

Все данные демонстрационные, на 8 сентября. Нет сети, внешних библиотек, реальной отправки сообщений или сохранения после перезагрузки.

# Атлас проектов

Главная — карта портфеля: у каждого проекта видны ближайший результат и одно конкретное включение владельца. Горизонтальные строки сохраняют соседство инженерных и агентских проектов, а правая «карта проекта» возвращает в контекст через точку остановки, чеклист и ожидаемых участников.

ContentOps, ChatGoose и Hub соседствуют с наймом и производством контента. Трафик, который ждёт подрядчика, вынесен ниже активных строк с датой возвращения. Отложенные проекты и уже закрытые результаты раскрываются отдельно. Тёмная графитово-синяя палитра, холодные голубые акценты и чёткий гротеск создают спокойный рабочий атлас с хорошо читаемым контекстом каждого проекта.

Компромисс: вид хорошо помогает восстановить контекст нескольких проектов, но не показывает всю очередь задач каждого проекта. Для исполнения большого бэклога нужен следующий уровень детализации.

Демонстрационные взаимодействия: выбор проекта с обновлением контекста; фильтр «Все / Разработка / Агентство»; отметки чеклиста; раскрытие отложенных проектов и закрытых результатов. Состояние хранится только в памяти и сбрасывается при перезагрузке. На мобильном карта выбранного проекта расположена под списком. Данные и промежуточные пункты чеклистов иллюстративны; весь экран помечен как демо.

# Фокус

TaskIndex как личный рабочий стол: одна текущая задача занимает главное место. Внутри сразу видны следующий шаг, небольшой объём работы и прогресс. Никаких колонок, бесконечной очереди или давления дедлайнами.

После текущей задачи — два понятных выбора. Справа отдельно стоят ожидания с человеком и датой возврата, затем сохранённые точки продолжения. При переключении прежняя задача попадает в «Легко вернуться». Проекты и остальные состояния доступны через «Все контексты».

Визуальная идея: тёплая бумага, тёмные зелёные чернила, крупная книжная типографика для текущей задачи и один терракотовый акцент. Асимметрия отделяет собственное действие от фоновых ожиданий.

Компромисс: стартовый экран намеренно показывает небольшой срез работы. Для обзора всей загрузки нужно открыть список контекстов и фильтры.

Демонстрационные взаимодействия:

1. Отметить шаги текущей задачи; счётчик и полоса обновляются.
2. Взять следующий или сохранённый контекст в фокус; прежний остаётся доступен для возврата.
3. Открыть контекст задачи и посмотреть состояние, следующий шаг и заметку; окно закрывается по Escape.
4. Открыть все контексты и отфильтровать по проекту или состоянию; «Отложенные контексты» сразу включает нужный фильтр.

Самодостаточный HTML, без сетевых запросов. Все изменения живут до перезагрузки. Задачи, сроки и состояния помечены как демонстрационные.
